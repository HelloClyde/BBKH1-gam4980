# H1 GAM4980

步步高 H1 / Y100 原生 `.gam` 模拟器，采用独立的 H1 原生程序框架。
核心来自 [BBK9588-gam4980](https://github.com/HelloClyde/BBK9588-gam4980)，
文件选择器、原生窗口、中文触摸菜单和启动框架参考
[BBKH1-GBA](https://github.com/HelloClyde/BBKH1-GBA)，使用
[H1 SDK](https://github.com/HelloClyde/bbk-h1-bda-sdk)。

## 安装

解压 `dist/H1GAM4980-install.zip`，将两个目录合并到 H1 的 A 盘：

```
A:\应用\程序\H1GAM4980.bda
A:\gam4980\8.BIN
A:\gam4980\E.BIN
```

把 `.gam` 游戏放入 `A:\gam4980\`，启动应用后用系统文件选择器打开。
也可以从其他目录选择，支持 GBK 中文文件名。游戏大小为 70 字节至 1920 KiB。
两个运行文件均须为 2 MiB。安装包不包含商业游戏。

应用图标采用与 H1 桌面一致的玻璃高光圆角风格，主体为学习机和像素游戏屏幕。
图标素材及生成说明见 [assets](assets/README.md)。

v0.1.3 优化绘屏：直接从 LCD 位图更新 RGB32 中变化的行，缓存放大坐标，
底栏只在返回游戏等需要完整重画时更新；正式版关闭每次按键的同步 NAND 日志。
修复按住返回键时可能连续切换菜单的问题。核心 CPU 和定时器速度保持不变。
等比例放大全屏变化时，绘屏指令量比 v0.1.2 减少约 79%；这不是实测真机帧率。

v0.1.4 把底栏改为四个可配置的游戏快捷键，在暂停菜单「按键设置」中设置。

v0.1.6 修复核心 BRK 后自动关闭游戏的问题：保留首次停止地址并停止运行核心，
显示可操作的结束菜单，支持重新开始、更换游戏、退出。最近 64 条实体事件／游戏按键
在 RAM 中记录，只在暂停、核心停止或退出时批量写日志；启动还记录游戏 CRC 和有效方向键映射。
v0.1.7 已根据随后收到的真机日志确定键盘映射原因。

v0.1.7 根据真机日志修复原因：键盘左／右的矩阵码 26／28 曾误标为 ALT，默认发送菜单／帮助。
现在两组左右键都发送正确方向，设置菜单也支持两组方向键。旧 `.cfg` 中这两项的错误默认值
自动迁移为方向键，保留其他自定义绑定及存档。

## 操作

- 暂停菜单底部的「关于」展示作者 HelloClyde、引擎作者无云和 iyzsong，以及步步高电子词典游戏群（830340878）的致谢。返回键、ESC、确认键或触摸「返回菜单」回到暂停菜单。

- 字母键、方向键、回车、空格、Shift、删除、上下页对应原机按键。
- Escape 对应游戏内的「退出」键；返回键打开应用暂停菜单。
- 点击游戏画面或按实体返回键暂停；提供继续、显示大小、LCD 颜色、按键设置、更换游戏及退出应用。
- 底栏默认「菜单、确认、退出、帮助」，点击后发送相应的原机游戏按键，游戏继续运行。其中「菜单／退出」是原机按键，其作用由游戏决定。
- 「按键设置 → 底栏快捷键」可分别设置四个位置，选择器分三页列出全部 59 个原机按键（字母、方向、数字和功能键），支持触摸或方向键／确认；返回取消选择，可恢复默认。
- 快捷键按游戏保存在 `.gam.hot.s0` / `.hot.s1`，独立于实体映射，不影响已有 `.cfg` 配置或游戏存档。
- 「显示大小」列出原始大小、等比例放大、整数倍放大（2倍）；整数模式为居中的 318×192，保持每个源像素对应 2×2 像素。
- 「LCD 颜色」列出原色（灰白）、绿色、蓝色、黄色；两种选项页均标出「已选」，暂停菜单也展示当前值。选择时游戏保持暂停，返回上级菜单后继续游戏。
- 使用 H1 实体全键盘；不提供软键盘。键盘左／右和另一组左／右均对应原机方向；FN 对应发音，符号键对应输入。菜单／帮助可用底栏快捷键或自行绑定。
- 「按键设置 → 实体按键映射」可把原机菜单、发音、清除、帮助、搜索、数字等功能绑定到实体键。选择目标功能后按所需实体键，返回或 ESC 取消；可恢复默认。
- 映射按游戏保存在 `.gam.cfg.s0` / `.cfg.s1`；绑定字母键会替换它原有的字母输入。Escape 保留游戏内退出，返回保留应用菜单。
- 暂停菜单「更换游戏」保存并重新打开选择器。选择器中取消退出应用。
- 字母 P、M、F、V 是游戏输入，不占用作应用快捷键。

存档使用游戏旁的 `game.gam.s0` / `.s1`，按 CRC 和序号轮换，写完关闭并读回校验。
每十秒、暂停、换游戏和正常退出时保存变化；两个存档同时损坏时保留文件并禁用本次保存。
此格式不同于参考项目的原始 `.sav`，不自动导入。
日志为 `A:\gam4980\h1gam.log`，启动覆盖；报告故障前请先复制日志。

## 构建

在仓库根目录执行：

```powershell
python tools/build_gam4980.py
python tools/build_gam4980.py --test-frames 12
python gam4980/tests/mips_smoke.py
```

使用固定版本 `sdk` 子模块 和 `.tools/toolchain/bin`；可用 `--toolchain` 或 `H1_GNU_BIN` 指定工具链。
SDK 锁定 `067fe072477861dfc8949d7b1a55279fb92d2548`，核心源快照锁定
`73b884a056ca0595de1552e6e365138687fb25a1`。s6502 文件原样保留；v0.1.6 在核心帧调度中检测 BRK，
避免停止后继续执行、覆盖首次停止地址。兼容头映射类型及内存复制；没有使用 9588 固件地址。
程序按实测固件 tick 频率调度 60 Hz 核心，只显示最新 LCD 状态。
启动时以 RTC 秒边界测量固件 tick 的真实频率；部分固件环境中名称为 80 Hz 的接口
实际只有 40 Hz，v0.1.5 已按测量结果调度，避免逻辑速度减半。

## 性能诊断 v0.1.5

解压 `dist/H1GAM4980-profile-install.zip`，合并到 H1 的 A 盘。
它会安装为同一个 `应用/程序/H1GAM4980.bda`；诊断版保留原来的操作及存档格式。
安装包不包含 `.gam` 游戏。

1. 打开《伏魔记》，在慢的场景游玩约 30 秒。
2. 按实体返回键进入暂停菜单，等菜单显示后正常退出应用。
3. 把 `A:\gam4980\h1gam.log` 复制到电脑。重新启动应用会覆盖日志，先保存这份文件。
4. 若要比较尺寸，可先跑默认等比例模式，暂停后切换整数 2 倍／原始尺寸，再继续约 30 秒并暂停。

日志记录核心、LCD 捕获、屏幕输出、输入、存档、等待和其他耗时，另有核心每帧耗时直方图、
平均／最长／P95 分箱范围、超出 16.67 ms 的次数、输入查询量、变化行／像素数及补帧丢弃量。
直方图按 1 ms 分箱，最后一箱表示 ≥63 ms；第 0 箱表示小于 1 ms，并非零耗时。
分项时间互斥，包含发生在该阶段的固件中断／调度时间；运行时仅在 RAM 汇总，暂停或退出
才批量写日志。加载、校准、菜单和诊断日志写盘时间不计入游戏窗口。
保留每次连续运行最后 12 个约 300 逻辑帧窗口；较早窗口会标明省略数。

```powershell
python tools/build_gam4980.py --profile
python tools/analyze_gam4980_profile.py h1gam.log --environment real-h1 --output gam-profile.json
```

使用 GBA 模拟器同样的 TCU5 RTC 计时方案，先校准，暂停／退出时恢复寄存器。
若计时器忙、读数异常或长停顿使回绕判断不可靠，分析工具拒绝生成耗时比例；
可加 `--coarse-only` 提取 RTC 的近似帧率范围。诊断失败时游戏仍可继续。
固件 tick 自校准结果记录为 `PACE_CLOCK`，没有有效 RTC 时明确标记失败并回退 80 Hz。
当前完整固件模拟器已复现旧调度约 30 逻辑帧／秒；真机的频率和瓶颈仍应以真机日志确认。
