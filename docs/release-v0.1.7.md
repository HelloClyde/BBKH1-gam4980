步步高 H1 / Y100 原生 GAM4980 模拟器首次独立发布。

- 实体全键盘、可配置功能键与四个底栏快捷键。
- 原始大小、等比例放大、整数 2 倍显示及四种 LCD 配色。
- 脏行绘屏、实际 tick 频率校准、CRC 双槽存档与配置。
- 修复矩阵码 26/28 被误映射为菜单/帮助；旧默认配置自动迁移，保留其他自定义映射和存档。
- 核心 BRK 后显示可操作的结束菜单；诊断版统计 TCU5 耗时分布。

下载 `H1GAM4980-install.zip`，将其中目录合并到 H1 的 A 盘。
`H1GAM4980-profile-install.zip` 为同一安装位置的诊断版；游戏需自行准备。
安装包内运行 ROM 的来源及独立许可缺项见仓库 NOTICE.md。

通过 BDA 静态校验、MIPS 回归、存档/键盘/快捷键测试和主机计时测试。
确切诊断版另有完整 H1 固件模拟器中的地图方向键验证；尚未收到修复版真机复测确认。
暂不支持声音、即时存档或旧存档格式转换。校验文件为 SHA256SUMS.txt。
